# Скриншоты

Кадры для основного README. Почти у каждого два варианта, `-light` и `-dark`:
README показывает тот, что совпадает с темой GitHub у читателя.

| Файл | Что на кадре | Где снято |
|---|---|---|
| `home` | Главная: трасса «М-4», билборд, цифры сети | `/` |
| `map` | Карта с секторами обзора и карточкой медиафасада в окне | `/map`, приближение к Воронежу |
| `surface` | Карточка экрана: форматы выхода, техтребования, календарь | `/surface/<id>` |
| `landing` | Посадочная города (только светлая) | `/reklama/voronezh` |
| `mobile` | Телефон: главная, карта, карточка экрана | те же страницы, 390 px |
| `staff` | Панель сотрудника: начальная страница с разделами | `/staff` |
| `report` | «Рекламные возможности» — матрица занятости | `/staff` |
| `order` | Заказ покупателя: размещения рекламы | `/staff` |

## Как снято

- Headless Chrome, окно 1920×1080, масштаб 1. Билборд на главной
  показывается от 1280 px, трасса — от 1800 px, поэтому ширина именно такая.
- Телефон — 390×844 с плотностью 3, коллаж собран из трёх кадров.
- Формат — WebP: панель без потерь (плоские цвета жмутся лучше PNG), фото и
  карта — с качеством 92.

## Чужие данные

Публичные страницы сняты с боевого сайта как есть, там только каталог.

Панель сотрудника снята на демо-данных: каталог поверхностей настоящий
(он публичный), а клиенты, заказы, менеджеры и арендаторы в отчёте выдуманы.
Снимать панель на боевых данных нельзя: там реальные организации, суммы
сделок, телефоны и реквизиты.
